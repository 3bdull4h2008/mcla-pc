# D3D12 / DXGI platform reference — read the header, not memory

**Scope.** Only the D3D12/DXGI surface `src/**` actually touches. A full API reference rots and
invites more recall-by-memory. If a name is not in a header listed below it does not appear here as
fact. If you cannot find a name in these headers, write `UNVERIFIED` and say which header you
searched — do not fill the gap from memory. That failure mode is what produced the 12 invented
names in §6.

## Anchor convention (machine-checkable)

Every entry carries a backticked anchor of the form:

```
`d3d12.h:3540`
```

= *file stem* `:line`. `d3d12.h` resolves under §"Header roots"; `dxcapi.h` is the **vendored** copy
under `third_party/dxc/inc/dxc/` and is marked `(vendored)` wherever cited. A tool can verify a row
by reading that exact line of that exact file and comparing the token. Rows with no anchor, or
marked `UNVERIFIED`, are deliberately not machine-checkable — treat them as claims, not facts.

### Two premises in circulation that are WRONG — measured, not assumed

- **`D3D12_COMPARISON_FUNC::NEVER` is 1, not 0, in SDK 26100.** The enum begins with an extra
  `D3D12_COMPARISON_FUNC_NONE = 0`; `NEVER` is 1 and `ALWAYS` is **8**. D3D11 and the D3D12
  docs-prose habit both say `NEVER`=0; this header does not. Check the header for the Kits you build
  against before assuming either. → `d3d12.h:1586`
- **`D3D12_RASTERIZER_DESC::DepthBias` is `INT`, not `FLOAT`.** The three "depth bias floats" are
  `DepthBiasClamp` and `SlopeScaledDepthBias` only. `DepthBias` became `FLOAT` in
  `D3D12_RASTERIZER_DESC1`/`2`; the plain `D3D12_RASTERIZER_DESC` the project uses still has `INT`.
  There is **no enable bit** for depth bias in any of the three — "disabled" means all three zero.
  → `d3d12.h:1771` vs `d3d12.h:1786`

### 6.2 The silent class: names that exist but lie

These compile clean and render wrong. Check them by eye, not by the compiler.

| Tempting name | Value you would get | What that value really is | Anchor |
|---|---|---|---|
| `..._MIN_LINEAR_MAG_MIP_LINEAR` | `0x11` | `..._MIN_LINEAR_MAG_**POINT**_MIP_LINEAR` | `d3d12.h:3546` |
| `..._MIN_MAG_MIP_LINEAR` | `0x15` | **legal** `..._MIN_MAG_MIP_LINEAR` — but note `0x14` is `MIN_MAG_LINEAR_MIP_POINT`; the min/mag pair is not symmetric in the spelling, so a hand-typed `0x14`/`0x15` swap silently bilinear-filters min | `d3d12.h:3547` |
| `kD3D12FilterMinPointMagMipPoint` (project name) | `0x004` | value is right, name is wrong — see §6.1 | `d3d12.h:3543` |
| `D3D12_COMPARISON_FUNC_NEVER` as `0` | `0` | `NONE`, i.e. comparison disabled | `d3d12.h:1586` |

### 5.2 The rules that bite

- **Root cost is 64 DWORDs** (`d3d12.h:1112`). A table costs 1 DWORD per descriptor range, a
  descriptor root 1, a 32-bit constant root 1. Three parameters with two tables and one CBV costs
  3. Headroom is not the constraint here; overlapping registers are.
- **A shader register may be claimed exactly once across all parameters, ranges *and* static
  samplers.** A static sampler at `s0` **and** a `SAMPLER` table range at `s0` is a validation
  error, not a shadowing situation — which is why `NumStaticSamplers = 0` /
  `pStaticSamplers = nullptr` at `src/d3d12_backend.cpp:1883-1884`. Setting
  `NumStaticSamplers = 0` while leaving `pStaticSamplers` pointing at a live array is the other
  half of the bug; both must be consistent.
- **Descriptor table ranges must be in ascending register order and non-overlapping** within a
  table, and `OffsetInDescriptorsFromTableStart` must match that layout. With a single range per
  table the offset is 0.
- **`NumDescriptors` is a count, not an end register.** SRV table 0 with `BaseShaderRegister = 0`
  and `NumDescriptors = 4` binds `t0 t1 t2 t3` — it does not bind `t4`, and it does not bind
  `t0..t3` plus a sentinel. The sampler table's `NumDescriptors = 1` binds **`s0` only**; a shader
  reading `s1` is unbound and reads garbage.
- **`D3D12_DESCRIPTOR_HEAP_FLAG_SHADER_VISIBLE`** is required for any heap whose descriptors are
  passed to `SetGraphicsRootDescriptorTable`. The RTV heap (`:527`) is *not* shader-visible — RTVs
  are only ever written via CPU handles.
- **One heap per type.** CBV/SRV/UAV share `D3D12_DESCRIPTOR_HEAP_TYPE_CBV_SRV_UAV`; samplers need
  their own `SAMPLER` heap. `SetDescriptorHeaps` takes at most one of each type at a time.
- **Root signature flags** (`d3d12.h:4065`): `NONE`=0, `ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT`=0x1,
  `DENY_VERTEX_SHADER_ROOT_ACCESS`=0x2, `DENY_HULL_SHADER_ROOT_ACCESS`=0x4,
  `DENY_DOMAIN_SHADER_ROOT_ACCESS`=0x8, `DENY_GEOMETRY_SHADER_ROOT_ACCESS`=0x10,
  `DENY_PIXEL_SHADER_ROOT_ACCESS`=0x20, `ALLOW_STREAM_OUTPUT`=0x40, `LOCAL_ROOT_SIGNATURE`=0x80,
  `DENY_AMPLIFICATION_SHADER_ROOT_ACCESS`=0x100, `DENY_MESH_SHADER_ROOT_ACCESS`=0x200,
  `CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED`=0x400, `SAMPLER_HEAP_DIRECTLY_INDEXED`=0x800.
  **`ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT` is mandatory here** (`:1885`) because the PSO supplies an
  `InputLayout` (`src/d3d12_backend.cpp:1910-1919`) — omit it and `CreateGraphicsPipelineState`
  fails with "input layout is not set in the root signature". `DEFINE_ENUM_FLAG_OPERATORS` is
  declared at `d3d12.h:4082`, so `|` on this enum is legal.
  **Flag ordering trap:** in the *IDL*/`d3d12.idl` the flags are ordered
  `ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT`, `DENY_VERTEX`, `DENY_HULL`, `DENY_DOMAIN`,
  `DENY_GEOMETRY`, `DENY_PIXEL`, `ALLOW_STREAM_OUTPUT`, `LOCAL_ROOT_SIGNATURE`,
  `DENY_AMPLIFICATION`, `DENY_MESH`, `CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED`,
  `SAMPLER_HEAP_DIRECTLY_INDEXED` — a *decreasing* bit order that matches the numeric values above
  exactly. There is no separate "version 1.0" flag; the version is the `D3D_ROOT_SIGNATURE_VERSION`
  argument to `D3D12SerializeRootSignature`, not a struct field.
- **`pRootSignature` may be `nullptr`** on a PSO desc only when `LOCAL_ROOT_SIGNATURE` is set.
  The project always sets it explicitly (`:1916`).

### 5.3 Worked example that actually serializes

Verified field-by-field against the anchors above; this is the shape
`src/d3d12_backend.cpp:1840-1905` already uses.

```cpp
D3D12_DESCRIPTOR_RANGE srvRange{};
srvRange.RangeType                      = D3D12_DESCRIPTOR_RANGE_TYPE_SRV;      // d3d12.h:3995
srvRange.NumDescriptors                 = 4;              // t0..t3
srvRange.BaseShaderRegister             = 0;
srvRange.RegisterSpace                  = 0;
srvRange.OffsetInDescriptorsFromTableStart = 0;

D3D12_DESCRIPTOR_RANGE samplerRange{};
samplerRange.RangeType                  = D3D12_DESCRIPTOR_RANGE_TYPE_SAMPLER;  // d3d12.h:3998
samplerRange.NumDescriptors             = 1;              // s0 only
samplerRange.BaseShaderRegister         = 0;
samplerRange.RegisterSpace              = 0;
samplerRange.OffsetInDescriptorsFromTableStart = 0;

D3D12_ROOT_PARAMETER p[3]{};
p[0].ParameterType = D3D12_ROOT_PARAMETER_TYPE_DESCRIPTOR_TABLE;               // d3d12.h:4045
p[0].DescriptorTable.NumDescriptorRanges = 1;
p[0].DescriptorTable.pDescriptorRanges  = &srvRange;
p[0].ShaderVisibility = D3D12_SHADER_VISIBILITY_ALL;                          // d3d12.h:4032

p[1].ParameterType = D3D12_ROOT_PARAMETER_TYPE_DESCRIPTOR_TABLE;
p[1].DescriptorTable.NumDescriptorRanges = 1;
p[1].DescriptorTable.pDescriptorRanges  = &samplerRange;
p[1].ShaderVisibility = D3D12_SHADER_VISIBILITY_ALL;

p[2].ParameterType = D3D12_ROOT_PARAMETER_TYPE_CBV;                           // d3d12.h:4047
p[2].Descriptor.ShaderRegister = 0;          // b0
p[2].Descriptor.RegisterSpace  = 0;
p[2].ShaderVisibility = D3D12_SHADER_VISIBILITY_ALL;

D3D12_ROOT_SIGNATURE_DESC rs{};
rs.NumParameters   = 3;
rs.pParameters     = p;
rs.NumStaticSamplers = 0;                   // MUST agree with the next line
rs.pStaticSamplers = nullptr;
rs.Flags = D3D12_ROOT_SIGNATURE_FLAG_ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT;     // d3d12.h:4068

ComPtr<ID3DBlob> blob, err;
HRESULT hr = D3D12SerializeRootSignature(&rs, D3D_ROOT_SIGNATURE_VERSION_1_0, &blob, &err);
if (FAILED(hr)) { /* read err->GetBufferPointer(): it names the bad parameter */ }

ComPtr<ID3D12RootSignature> sig;
hr = device->CreateRootSignature(0, blob->GetBufferPointer(), blob->GetBufferSize(),
                                 IID_PPV_ARGS(&sig));
```

The four things that make this serialize rather than fail: `NumStaticSamplers` and
`pStaticSamplers` agree; no register is claimed twice (`t0..t3`, `s0`, `b0` are disjoint
spaces/classes); each table's ranges are ascending and non-overlapping; and
`ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT` is present for the PSO's input layout.

## 7. Vendored DXC headers — measured, and they do **not** differ where it matters

`third_party/dxc/inc/dxc/d3d12shader.h` (27161 B, LF) vs
`um/d3d12shader.h` (28117 B, CRLF). Normalised for whitespace, the two files differ by **exactly
five lines, all of them in the SDK's favour**:

| Extra in the **SDK** copy | Anchor |
|---|---|
| `D3D12_SHVER_NODE_SHADER = 15` | `d3d12shader.h:40` |
| `D3D_SHADER_REQUIRES_ADVANCED_TEXTURE_OPS 0x20000000` | `d3d12shader.h:206` |
| `D3D_SHADER_REQUIRES_WRITEABLE_MSAA_TEXTURES 0x40000000` | `d3d12shader.h:207` |
| `D3D_SHADER_REQUIRES_SAMPLE_CMP_GRADIENT_OR_BIAS 0x80000000` | `d3d12shader.h:208` |
| `D3D_SHADER_REQUIRES_EXTENDED_COMMAND_INFO 0x100000000ull` | `d3d12shader.h:209` |

Nothing is SDK-only beyond those five; nothing is vendored-only. A declaration-level diff
(62 struct fields, enum members and `STDMETHOD` signatures in each) returns **zero** differences.
The remaining ~956 bytes of the size gap are the 494 CRLF line endings. Both files define
`D3D12_SHADER_BUFFER_DESC` with the count member spelled **`Variables`** — *not* `VariableCount`
(SDK `d3d12shader.h:81`, vendored `:79`).

**Which one compiles:** the SDK's. The only include site is
`src/renderer/dxc_runtime.cpp:12` — `#include <d3d12shader.h>`, unqualified. `CMakeLists.txt:153`
sets `DXC_INCLUDE_DIR` = `third_party/dxc/inc`, and `CMakeLists.txt:530` adds it, but the vendored
file lives at `inc/**dxc**/d3d12shader.h`, so the unqualified path does not resolve there and falls
through to the SDK's `um/d3d12shader.h`. Nothing in `src/**` includes `<dxc/d3d12shader.h>`.
**Cite the SDK line numbers, not the vendored ones.**

Consequently the comment block at `src/renderer/dxc_runtime.cpp:339-366` reaches the right
conclusion — no `GetVariableDesc`, no `GetVariableCount`, no `GetVariableByIndex` on
`ID3D12ShaderReflection`; the CBV size comes from
`ID3D12ShaderReflectionConstantBuffer::GetDesc(D3D12_SHADER_BUFFER_DESC*)` → `.Size`
(SDK `d3d12shader.h:356`, reached via `GetConstantBufferByIndex` at `:384`) — but it attributes the
absence to
`third_party/dxc/inc/dxc/d3d12shader.h`, which is not the file being preprocessed. Correct in
substance, mis-cited in origin. `dxc_runtime.cpp:363-366` also notes there is no `VariableCount`
field; the defensive `cbuf->GetVariableByIndex(0)` probe is sound and its `nullptr` check is the
right guard.

The vendored `dxcapi.h` (53314 B) defines **no** `IDxcReflection` interface and no
`GetVariableDesc` — reflection goes through the D3D11-era `ID3D12ShaderReflection` vtable only.
`dxcisense.h` (41969 B) and `dxcpix.h` (7720 B) ship in the vendored tree but the project includes
neither, so they are out of scope.
