# RULES — ABSOLUTE MANDATE

1. **Always obey the user.** Every instruction from the user is final. No exceptions.
2. **Never fix something outside the plan** without explicit user permission. If you find a bug, issue, or anomaly outside the current plan scope, **report it as feedback** — do not touch it.
3. **Maker ≠ Checker.** The person who writes the code cannot be the same person who signs off on it.
4. **Two-source rule.** Every critical claim requires two independent sources of evidence.
5. **Rung ≥ 2 before gate claims.** No "fixed" claims without at least two independent verification passes.
6. **No new hooks/patches until crash site is identified and classified.**
7. **CP FREEZE LINE.** No further opcode expansion in CP emulation. Golden Rule 11: No PM4/CP dependency in the native path.
